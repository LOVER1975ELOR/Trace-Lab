Environment
  Original run: Ubuntu 24.04.5 LTS, x86-64, kernel 6.17.0-40-generic,
  perf 6.17.13. Use the same kernel and compatible Ubuntu userspace to reproduce
  the reported function names and tracing interfaces. The executable is the
  assignment's supplied binary and is run directly.

  Required tools: Bash, sudo, perf matching the running kernel, util-linux
  (setpriv/findmnt), procps (ps), coreutils, grep, sed, and awk.
  On Ubuntu, install matching Perf tools if necessary:

    sudo apt install linux-tools-common "linux-tools-$(uname -r)"

  The kernel must provide tracepoints, kprobes, and function_graph support.
  TraceFS must be mounted at /sys/kernel/tracing. Check with:

    uname -r
    perf --version
    findmnt /sys/kernel/tracing

  If TraceFS is not mounted:

    sudo mount -t tracefs tracefs /sys/kernel/tracing

  Run the commands below as a normal user with sudo access. The scripts elevate
  individual tracing commands and run the supplied program as the normal user.
  Script 08 uses the main ftrace instance, saves its previous buffer, and restores
  the original tracer settings. Its preflight protects existing custom settings.

Create a fresh experiment directory
  Run this block from the extracted lab2 directory. It copies the inputs into a
  new sibling directory so that all original measurements remain available:

    lab2_package="$PWD"
    lab2_rerun=$(mktemp -d "$lab2_package/../lab2-rerun-XXXXXX")
    cp -a scripts src "$lab2_rerun/"
    mkdir -p "$lab2_rerun/logs/perf" "$lab2_rerun/logs/ftrace" "$lab2_rerun/logs/runs" "$lab2_rerun/notes"
    chmod u+x "$lab2_rerun/src/program"
    cd "$lab2_rerun"

Record baseline, environment, and event discovery
  Continue in the same Bash terminal:

    sudo -v
    { date -Is; cat /etc/os-release; uname -r; perf --version; sudo cat /sys/kernel/tracing/available_tracers; } > notes/environment.txt
    sha256sum src/program > notes/program_sha256.txt
    ./src/program > logs/program_baseline.stdout 2> logs/program_baseline.stderr
    printf 'Program exit code: %s\n' "$?" > logs/program_baseline.status
    sudo perf list tracepoint > notes/perf_tracepoints.txt
    grep -E 'kmem:|net:netif|syscalls:sys_(enter|exit)_mmap|tcp:|i2c:' notes/perf_tracepoints.txt > notes/perf_target_events.txt
    sudo perf stat -e syscalls:sys_enter_mmap,syscalls:sys_exit_mmap -o logs/perf/mmap_stat.txt -- setpriv --reuid="$(id -u)" --regid="$(id -g)" --init-groups -- ./src/program > logs/perf/mmap_program.stdout 2> logs/perf/mmap_stat.stderr

  The PDF identifies the original counts, durations, and evidence files.
  notes/report_numeric_verification.txt verifies those archived measurements.
  Fresh runs naturally produce different addresses, timings, and some counts.
